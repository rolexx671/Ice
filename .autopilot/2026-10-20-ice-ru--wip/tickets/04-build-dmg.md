# 04 — Сборка: всё компилируется, скрипт DMG

**Требования:** R05, R06, R07i
**Зависит от:** 01, 02, 03
**Зона:** `scripts/` · `.gitignore` · `Ice.xcodeproj/` · любые исправления компиляции в `Ice/`
**Волна:** 2
**Ревью:** нет
**Модель:** сильная

## Что должно заработать

Одной командой `scripts/build-dmg.sh` из переведённого кода получается
`dist/Ice-<версия>-ru.dmg` с `Ice.app` (ad-hoc подпись, без аккаунта разработчика)
и ярлыком «Программы». Сборка без ошибок.

## Из брифа, дословно

> «выкатывай в dmg»
> «установи на мой мак»

## Разделы спецификации

R05, R07i; `interfaces.md` — «Стек и команды», «Сборка».

## Критерии приёмки

- [ ] Полная ad-hoc сборка Release проходит без ошибок (ошибки компиляции после перевода исправлены без изменения логики и без возврата английского)
- [ ] `scripts/build-dmg.sh` (bash, `set -euo pipefail`) собирает, подписывает ad-hoc (`codesign --force --deep --sign -`), проверяет `codesign --verify`, создаёт `dist/Ice-<MARKETING_VERSION>-ru.dmg` через `hdiutil` с `Ice.app` и симлинком `Applications`; при ошибке — код ≠ 0
- [ ] `scripts/install-from-dmg.sh <dmg>` монтирует образ, завершает запущенный Ice, копирует `Ice.app` в `/Applications` (с заменой), отмонтирует, снимает карантин и запускает приложение; при ошибке — код ≠ 0. Сам скрипт в этом таске НЕ запускать — установку делает оркестратор после приёмки
- [ ] `dist/` и `build/` в `.gitignore`
- [ ] Финальный grep по всему `Ice/` (из `interfaces.md`) — английских видимых строк не осталось; найденные остатки переведены
- [ ] В собранном `Ice.app/Contents/Info.plist` нет `SUFeedURL`
