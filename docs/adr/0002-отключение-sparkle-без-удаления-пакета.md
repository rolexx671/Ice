**Контекст**
Оригинальный Ice обновляется через Sparkle с фида апстрима. Обновление затёрло бы русскую сборку английской.

**Решение**
Из `Info.plist` убраны `SUFeedURL` и `SUPublicEDKey`, апдейтер создаётся незапущенным, раздел «Обновления» в «О программе» и пункт «Проверить обновления…» в меню убраны. Зависимость Sparkle остаётся в проекте.

**Почему**
- Оставить включённым и «просто не публиковать» отвергнуто: фид апстрима живой, первая же проверка предложит английскую версию.
- Убрать только ключи фида отвергнуто как недостаточное: без UI пользователю остаются мёртвые кнопки, а апдейтер всё равно стартует и пишет ошибки.
- Полностью удалить пакет Sparkle отвергнуто: правка проекта и связанного с ним кода рискованнее пользы, сборка может сломаться.

**Последствия**
- Обновления только пересборкой форка вручную.
- Sparkle остаётся в сборке: лишний вес и мёртвый код (заглушки менеджера обновлений, уведомление об обновлении), которые читатель должен уметь отличать от рабочего.
- Любое слияние апстрима, трогающее обновления, конфликтует с этим решением.
