**Контекст**
Форк можно переименовать и дать ему свой bundle id. На машине пользователя оригинального Ice нет, конфликтов нет.

**Решение**
`PRODUCT_BUNDLE_IDENTIFIER` остаётся `com.jordanbaird.Ice`, `MARKETING_VERSION` остаётся 0.11.12. Русская сборка отличается только суффиксом `-ru` в имени DMG.

**Почему**
- Свой bundle id отвергнут: смена сбрасывает выданные разрешения TCC и сохранённые настройки, то есть русский Ice стартовал бы чужаком для системы и без прежней конфигурации.
- Свой номер версии отвергнут: нечему его сверять, обновлений нет, а совпадение с апстримом упрощает слияние.

**Последствия**
- Русский Ice и оригинальный не уживутся: общие настройки и разрешения, система считает их одним приложением.
- Оригинал придётся удалять, если он появится.
- По версии не отличить форк от апстрима; различает только имя DMG и README.
