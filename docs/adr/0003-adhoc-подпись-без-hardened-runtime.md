**Контекст**
У пользователя нет аккаунта Apple Developer; в проекте прописаны чужая команда разработчика и подпись «Apple Development». Нужна установка на свой Mac.

**Решение**
Сборка подписывается ad-hoc (`-`) без команды разработчика, с выключенным hardened runtime и без добавления базовых entitlements (`CODE_SIGN_INJECT_BASE_ENTITLEMENTS=NO`, то есть без `get-task-allow`). Для выбора ad-hoc достаточно `CODE_SIGN_IDENTITY=-`.

**Почему**
- Developer ID с нотаризацией отвергнута: нет аккаунта, а для своего Mac не нужна.
- Подпись «Apple Development» из проекта отвергнута: требует чужую команду и сертификат, которых нет.
- Вариант с условной настройкой `CODE_SIGN_IDENTITY[sdk=macosx*]=-` в командной строке отвергнут: ломает разбор аргументов, а одного `CODE_SIGN_IDENTITY=-` хватает.
- Hardened runtime выключен для локальной сборки: он нужен для нотаризации, которой нет.

**Последствия**
- Разрешения «Универсальный доступ» и «Запись экрана» пользователь выдаёт сам при первом запуске; после каждой пересборки macOS может спросить их снова. Это надо сказать в README.
- Без `get-task-allow` отладчик к собранному приложению не подключить.
- На другом Mac придётся снимать карантин (`xattr`): сборка не нотаризована.
- Защита рантайма слабее, чем у подписанной сборки.
