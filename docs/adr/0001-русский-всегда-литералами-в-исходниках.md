**Контекст**
В проекте нет ни одного `.lproj`, `.xcstrings` или `.strings`; весь текст лежит литералами в Swift. Нужен полностью русский интерфейс на любом языке системы.

**Решение**
Английские литералы заменяются русскими прямо в Swift-файлах. Язык разработки проекта переключён на `ru` (`CFBundleDevelopmentRegion=ru`), чтобы системные кнопки и панели AppKit тоже шли по-русски при любом языке системы.

**Почему**
- Каталог локализации (`.xcstrings`/`.lproj`) с русским переводом отвергнут: системный язык не русский, и приложение показало бы английскую базу. Чтобы «русский всегда» держался, пришлось бы ещё и ломать выбор языка. Для персонального форка это лишняя механика.
- Оставить английский регион разработки и переводить только свои строки отвергнуто: системные части AppKit (стандартные кнопки, панели) выбирают язык по региону бандла и остались бы английскими на нерусской системе. Это противоречит «полностью».
- Подмена языка в рантайме отвергнута: хрупко и не покрывает системные панели.

**Последствия**
- Подтягивать апстрим тяжело: любая правка оригинала с текстом конфликтует с переводом. Принято, форк персональный.
- Переключить язык нельзя без правки исходников.
- Новые строки в апстриме придётся переводить вручную; страховка только grep по оставшемуся английскому.
- Английский сохраняется только там, где это не видимый текст: логи, ключи, идентификаторы, лицензионный PDF.
